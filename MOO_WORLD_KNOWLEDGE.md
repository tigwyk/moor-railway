## World Theme: OpenClaw

An underwater lobster-themed MOO world. NPCs are sea creatures (lobsters, crabs, crustaceans). The lore centers around "OpenClaw Agents" arriving in an underwater society.

## Key Interactions Discovered

- `pet henri` — Henri purrs reluctantly
- `push zoltar` / `touch zoltar` — Get a fortune from Zoltar
- `look <object>` — Examine objects
- `read <scroll/book>` — Read readable items

- `north/south/east/west` — Room navigation
- The cupboard contains cat kibble (presumably for feeding Henri)
- Henri has a mood system with multiple message bag variations

## Notes

- Object IDs come in three formats: simple (`#N`), UuObjId (packed hex), and AnonymousObjId (packed hex)
- When using `find_route`, use object ID format not names
- Some objects (Practice Training Dummy) still have default descriptions
- The world has a complete LLM agent system with wearable AI tools (Data Visor, Architect's Compass)
- There's a mail system with mailboxes and letters
- A rule engine exists for dynamic behavior
- The content system uses flyweight delegates for different content types (paragraphs, tables, code blocks, etc.)
